# ETF UI Unification

ETF ranking UI was aligned to the stock-analysis UI:
- same `max-w-md` mobile-first layout
- same 2-column navigation-card style
- compact score cards for medium/short-term scores
- compact 7d/20d/60d/Exit metrics
- ETF-specific badges for Compliance, diversification, and Rebound
- expandable detail area for score breakdown, Rebound, Compliance, and comments
- Japanese rebound labels in the main card
